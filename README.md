
# Data Cleaning Task

## Objective
Clean and prepare the Mall Customers dataset using Microsoft Excel.

## Tools Used
- Microsoft Excel

## Cleaning Steps Performed

1. Checked for missing values using Filters.
   - No missing values were found.

2. Removed duplicate rows using Data → Remove Duplicates.
   - No duplicate records were found.

3. Checked text consistency.
   - Gender values (`Male`, `Female`) were already standardized.

4. Checked date formats.
   - No date column was present in the dataset.

5. Renamed column headers to make them clean and consistent.

6. Verified data types.
   - Age and income columns were numeric.
   - Gender column was text.

## Summary of Changes

- Missing Values: 0
- Duplicate Rows Removed: 0
- Column headers standardized
- Dataset verified and ready for analysis
